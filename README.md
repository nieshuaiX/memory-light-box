# 忆光匣 · Memory Light Box

> 与记忆中的人，重新说说话。

忆光匣是一台**本地的回忆体验装置**：用你自己的素材重建人物画像，回到那段时光里，把没说完的话说完。所有数据只留在你的电脑上。

**不编造，只留存 —— 你的记忆，留在你的电脑上。**

---

## 它是做什么的

给每个人心里那个「如果当时…」一个出口：

- 重要的人离开了，话却永远没说完
- 照片和聊天记录躺在硬盘里，再没打开过
- 「想回去看看」的念头，找不到出口
- 通用的聊天机器人，没有「那个人」的模样

忆光匣的回答：用你自己的素材重建 TA 的画像，与「记忆中的那个人」沉浸式对话；不编造、只留存，尊重记忆的边界。

## 三种进入回忆的方式

| 方式 | 适合谁 | 说明 |
|---|---|---|
| **导入构建** | 有聊天记录 / 文本素材 | 上传微信聊天记录、纯文本对话，AI 自动构建人物画像，进入宿命 / 逆转对话（主流程） |
| **书写回忆录** | 记忆只存在心里 | 引导式书写 + AI 温柔追问，帮你想起更多细节，让记忆逐渐清晰 |
| **独白模式** | 想与过去的自己对话 | 把日记 / 随笔归为「我」，构建「过去的我」的画像，和某个时期的自己说说话 |

## 两种对话模式

- **宿命模式**：你可以回去，可以重新走一遍，但改变不了什么——该发生的还是会发生。一种「温柔的残忍」，让你重新经历，也让你接受过去。
- **逆转模式**：你可以在某些节点做出不同选择，看看「如果当时…」会怎样。它有边界：只能在记忆涉及的范围内分支——这终究是回忆，不是平行宇宙。

## 隐私与伦理承诺

- **本地优先**：数据不上传任何服务器，全部存储在你自己的电脑上
- **不编造、只留存**：AI 不替你编造记忆，只陪你把回忆留住
- **自带密钥（BYOK）**：模型调用支持你自己的 Key，自主可控
- **随时导出**：回忆记录、回忆录可导出 txt / PDF / HTML
